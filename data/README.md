# Data

The labelled sample set cannot be released (institutional restrictions on the
field-survey data). To reproduce the analysis you need:

- data/features/YN_2024_TST_Ultra_v21_Positive_Samples{1km,2km,5km}.csv
- data/features/YN_2024_TST_Ultra_v21_Negative_Samples{1km,2km,5km}.csv
- outputs/<scale>/loro_result_<scale>.pkl
- outputs/<scale>/ablation_checkpoint_<scale>.pkl

Sentinel-1 and Sentinel-2 imagery is publicly available from the Copernicus
Data Space Ecosystem: https://dataspace.copernicus.eu
